# Original-source lineage follow-up for Tierney / Chen poll rows

## Scope and result

This is a read-only provenance follow-up to `m01-release-linkage-luna-v1`. It preserves that packet and its correcting addendum. No data were fitted, admitted, or copied into this directory. The result is that Tierney's published replication package can be traced to an author-maintained CSV named `polls_cnn_dataset.csv`, and the published Chen paper says Harry Enten at CNN supplied data. Neither available author-source object maps an individual Tierney CSV row to a named primary release, sample, questionnaire, or survey identifier. Consequently, the Arizona connection remains a strong content-compatible candidate, while the Emerson Missouri candidate remains ambiguous. Neither Tierney row is proven to be the same survey event at sample/question level.

## What author lineage is established

- Tierney's replication repository is `https://github.com/g-tierney/polling_errors_replication`, commit `4aba5bc539dde8157bb2eeae9f3330a01439c19d` (commit metadata identifies Graham Tierney and date 2023-03-08; unsigned). The exact dataset blob is `data/polls_cnn_dataset.csv`, Git blob `2b397788b99435522a7f051a4040bcd913c693f6`, 688,043 bytes, SHA-256 `61e1141f5ed84cfbbec487115742f59c6e20ebd04ba99a0a32f08d8fa2b20322`. Local evidence is in the already existing historical intake at `/home/hayden/projects/wethervane-redesign-20261006/integration/research/polling-layer-implementation-20261020/historical-intake-sol/source_receipt.json`; this follow-up does not duplicate the CSV, whose inspected upstream repository tree had no LICENSE file.
- The Tierney README describes a replication hub and says raw polling data are processed by `scripts/01_model_prepare_input.R`; it does not name original pollster releases per row. The R preprocessing script selects `data/polls_cnn_dataset.csv` for the Senate model, calculates Republican two-party share as `republican/(democratic+republican)`, computes days to election from `endDate`, and calculates effective n from the recorded respondent count times the D/R percentage sum. It does not ingest a release URL, question, or sample ID.
- The raw table has 18 columns: election, state, year, pollName, endDate, numberOfRespondents, democratic, republican, electionDate, startDate, someoneElse, undecided, refuseToAnswer, populationType, Mode, check, and two final-vote-share fields. It has no publication date, URL/citation, question, poll/sample identifier, or source lineage column. For each target row `startDate`, `populationType`, `Mode`, `check`, and non-D/R values are `NA`.
- In the paper “Polls, Context, and Time: A Dynamic Hierarchical Bayesian Forecasting Model for US Senate Elections,” Chen, Garnett, and Montgomery state that Senate poll data were obtained from CNN and FiveThirtyEight; the acknowledgments thank Harry Enten at CNN for providing data. The paper's data statement points to Code Ocean DOI `10.24433/CO.4154884.v1` and the preservation copy at Harvard Dataverse DOI `10.7910/DVN/GNHESM`. This establishes a plausible upstream author-data chain, not a row-level provenance map to Rasmussen or Emerson.
- Tierney and Volfovsky's later article “Bias and Excess Variance in Election Polling: A Not-So-Hidden Markov Model” says its Senate data cover 1992–2020 and relies on the Chen et al. Senate data. This supports the Tierney-to-Chen dataset lineage at collection level, not the poll event identity of an individual row.

## Retrieval attempts and blockers

- The Chen paper's cited Harvard Dataverse dataset is public and search-indexed as version 1.0 (DOI above); catalog results describe a 6 MB capsule and a 26.8 GB results archive. I did not retrieve the large results archive. Direct web access to the dataset page returned a bot-verification/JavaScript challenge; direct API attempts from the shell returned HTTP 403. Therefore no capsule file contents or possible row provenance metadata were inspected.
- The paper's PDF is publicly indexed at the NSF Public Access Repository and its search-indexed text supports the data-source and acknowledgment claims. Direct page fetching via the web opener failed (502); the indexed PDF text was available. The official Cambridge article metadata was also search-accessible. This is not a substitute for inspecting the replication files.
- No author-level row-source list or unique poll identifiers were found in the Tierney README, commit metadata, raw CSV structure, or preparation script. Access to the author's or CNN's unpublished delivery records was not available in this research pass.
