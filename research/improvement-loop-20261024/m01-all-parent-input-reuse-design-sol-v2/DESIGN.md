V2 output-attribution correction; no actual graph

Frozen V1 remains unchanged. Its bind function returned an immutable exposure tuple beside a mutable envelope dict; a caller could relabel that dict after binding. V2 replaces that pair with a frozen BoundParent object whose complete parent record and envelope are canonical immutable bytes and whose exposure is a tuple of tuples of floats. No dict/list is retained in a bound object. This addresses accidental mutation, not hostile Python code or arbitrary filesystem rewrites.

Every output must pass seal_output immediately before publication. It reloads the frozen source manifest, authenticates the entire parent record against exactly one of the eight original records, reconstructs the expected immutable object and compares all fields. It requires the exposure actually supplied by the caller and the claimed envelope; both must exactly match the reconstructed bound state. Parent ID, row ID, mass, reference target and exposure digest changes reject. A new output is built from authenticated canonical record/envelope bytes, not the caller's mutable claim. Returned output is canonical immutable bytes. verify_output later reconstructs the same whole parent and checks every envelope field plus exposure digest; it does not accept mutable dictionaries as its serialized input. Tests also deliberately bypass frozen assignment and prove final revalidation catches inconsistent envelope/exposure fields.

The helper receives exposure_used as a caller declaration. It does not execute a numerical kernel, inspect a callable, prove which input an arbitrary evaluator consumed or bind a real transformed point/result to actual graph execution. caller_kernel_id and caller_point_id are explicit untrusted caller identifiers, not authenticated graph or scientific target receipts. Outputs are labeled metadata consistency only, evaluator_authenticated=false, actual_conditional_normalization=unverified. A future evaluator wrapper must authenticate the compiled source/contract, own the call from a validated BoundParent, retain exact input and point bytes and bind its result and parent envelope atomically. That wrapper and actual execution are not implemented here. Merely passing verify_output is not permission to register, sample or predict.

The same frozen manifest preserves every full original parent record, axes, lineage and mass .125. Reference fixed-parent target IDs are exact formula references; only the first has an actual compiled baseline, and the remaining seven are not reified contracts. A generic input kernel never inherits the first parent's identity for another exposure. All fixed-mass population_cut_v1 requirements remain unchanged: normalize only inside each parent, combine normalized conditional results with .125, never use downstream Z to update outer parent masses. Exact invented finite-state tests preserve these masses under Z imbalance, but no actual normalizer or posterior is computed.

The staged scientific design from V1 remains applicable: one strict-exposure-replaced compressed Jacobian-inclusive logp/factor/rate kernel, compare parent0 to saved fixed-state baseline, independently form native fixed-parent B as an anchor, and keep missing remaining-row baselines explicit unless exhaustive reviewed source proof or later independent evaluations cover them. A→B→A isolates mutable state but cannot prove the port is consumed correctly or each conditional normalized. Reusing two target-coordinate points requires support/transform/physical-intensity/Jacobian checks for every parent.
