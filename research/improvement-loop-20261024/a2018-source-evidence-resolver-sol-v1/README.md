# Frozen A2018 prepared-source evidence resolver

This is a source-specific step beyond the generic claim checker. It opens and hashes exact frozen plan/context/problem/component/rank/open contribution bytes and the aggregate ledger/checker/closure adapter. It derives the mappings actually encoded in that prepared problem, not raw-question meanings or people identities. Output is aggregate only. No posterior/predictive arrays, model import/build/fit, owner edits, row-token export, ranking or release.

## Missing provenance is not filled in

Prepared survey keys/masks do not establish original source question/field identity, collection intervals, respondent identity or source-design independence. Poll row IDs are logit-statistic IDs, not unique sample/respondent IDs; source sample/date/mode/population/n and per-row exact publication evidence are not supplied here. Registry available_utc is a pinned claim, NOT independently verified availability of those exact historical bytes. Distinct source names or token sets do not prove cross-source disjointness. Equal used-source hash aliases are flagged unresolved; no absence-of-alias result is called disjointness. Derived-source/raw-field lineage still needs a separate source-reading admission adapter.

Therefore the generic V2 row audit is deliberately NOT invoked: original atom measurement lineage and exact-version/collection dates are missing/unsupported. No fabricated dates, manufactured canonical raw-question IDs or automatic exceptions are used to pass it. Only its literal-pinned aggregate consistency API is invoked, which returns record_ownership_audited=false and sampling_overlap=unknown. Both original-source atom authentication and respondent/sample independence remainfalse. Scientific qualification remainsfalse; eight original protected masses.125 and the unqualified plan are checked by the aggregate adapter.

## Binding and implementation boundaries

bindings.json is fixed by a SHA constant in resolver.py. All9selected files are checked by size and SHA before parsing/import. Pinned closure/checker adapters are standard-library metadata code, not model imports. Full output records aggregate counts/vector hashes/source hashes and audited-versus-blocked flags only. These are byte/version commitments, not a proof that source release claims were true or semantics originally admitted. Verification and local module import are not an atomic hostile-filesystem snapshot; the trusted workspace must remain stable. Source-preservation tests rehash inputs after use. Caller-authored coherent alternate bindings/code do not inherit this packet's admission.

inspect_prepared is an untrusted-fixture inspection helper; it does not authenticate its argument. Its altered-fixture results cannot substitute for resolve's exact pin path. The resolver is intentionally specific to this frozen A2018 problem. New source/version/measurement law needs a new reviewed binding, not a weakened pin check.
