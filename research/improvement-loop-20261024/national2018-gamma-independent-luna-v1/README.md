## Conclusion

The narrow source-level hypothesis is mathematically sound for the pinned 2018 Problem and extension, subject to source-lineage and finite-precision limits below: on positive support the current observed likelihood appears independent of `event_gamma_shape` and `eventG`. In this selected input, all 54 events use the ordinary unobserved-event `Gamma(kappa, kappa)` prior; there are no official-count or participation-report observations, all 274 poll rows are ordinary pairwise log-rate rows with fixed covariance, and `G` cancels from each `log(G r_a)-log(G r_b)` mean. The 7,968 survey rows use turnout/community/choice/reporting components without `G`. The extension has one ranked definition and one runoff definition but zero observations in both; open-person extension is null.

This supports investigation of a normalized prior-only block, not a qualified remedy or causal explanation of divergence. For any fixed parent, if `theta` denotes all remaining variables, the active likelihood factors as `L(D|theta)`, `kappa ~ LogNormal(log(100),0.7)`, and `G_e|kappa iid ~ Gamma(shape=kappa, rate=kappa)`. Since each conditional Gamma density integrates to one, integrating all `G_e` and then `kappa` leaves the conditional posterior law of `theta` unchanged. This statement is conditional on the selected Problem and source law, and it respects the declared fixed outer parent masses: no parent evidence reweighting is implied.

`eventG` remains essential to the generated law. Exact posterior-predictive reconstruction must draw one shared `kappa` and then all 54 `G_e` values conditional on that same `kappa`, before generating event participant counts. The same `G_e` and participant profile counts are shared across contests in its event. Marginally drawing independent per-event `G_e` from separate `kappa`s or setting `G=1` loses dependence and changes predictive count dispersion. Existing failed banks do not become qualified by dropping diagnostic coordinates.

## Conditions and counterexamples

The factorization requires all of the following: (1) every observed factor in the admitted graph is independent of `kappa/G`; (2) each Gamma prior is a properly normalized density on `G>0`, with its shape/rate law and any transform Jacobian preserved; (3) every ordinary polling mean uses the same positive event multiplier on both candidate category rates, with no additive rate floor; and (4) there are no active count, report, ranked, runoff, or open-person likelihood observations using event-scaled intensities.

An additive floor breaks the poll cancellation: `log(G*r_a+eps)-log(G*r_b+eps)` varies with `G` when `eps>0` (unless the floor is scaled by `G` too). No such floor is used by the selected ordinary-poll source path. Its separate ranked-poll helper receives cell intensity but not `eventG`, and the pinned problem has no ranked poll channel.

Other changes that break the hypothesis include any observed official counts (`Poisson` rates are `G*base_category_rates`; the observed-total event branch also constructs a Gamma density with coordinate Jacobian), participation reports (`NegativeBinomial` mean uses `event_intensity`), ranked/runoff count observations (Poisson intensities include `eventG`), or open-person count observations (Poisson intensities include `eventG`). A future poll factor based on sample totals or absolute counts would also need a fresh factor audit; the current poll likelihood only scores transformed pair log-ratios under fixed covariance.
