# Screening 2018 calibration support

This read-only inventory examines the earlier FiveThirtyEight snapshot from `m01-538-archive-root-v1`, without treating its observations as admitted model data. Run `python3 research/improvement-loop-20261024/m01-538-support-audit-root-v1/audit.py` and compare stdout with `support.json`. Both source CSVs are SHA-256 checked before use.

Among 465 Senate records from 2012 and 2016, 451 are standard-November-date polls whose first two candidates carry the source's generic Democrat and Republican labels. Four 2016 Louisiana records concern the December runoff; ten other records do not have that generic D/R pairing. These filters are screening criteria, not election-rule validation or an automatically selected training cohort. The source says first/second candidates are the election's top two finishers, a retrospective selection that must be limited to outcomes already known before the target forecast. The source's sample sizes can be estimated or defaulted, and its poll date is the median field date, not necessarily an end or publication date.

The 451 generic D/R records cover 58 coarse `(cycle, state)` keys; the existing prepared 2018 Tierney training file covers 59, with 57 shared state-year keys. Archive-only is 2016 GA; prepared-only are 2012 WV and 2016 AK. This is not a canonical race or question identity join. Special elections, multiple races, same-state runoffs, name conventions, source versions, sampling universe, publication timing and shared sample identities need separate review. A state-year overlap is no evidence that an individual poll is shared.

For a fair future experiment, first authenticate source dates, candidate identities and earlier outcomes; define eligible observations and canonical event keys; handle non-D/R and Louisiana separately; identify duplicated sample/question releases; and specify a matched age horizon, weighting, sample-size treatment and uncertainty law. Compare all arms on precisely the same authenticated source cohort and evaluation races before separately measuring any benefit from adding data. The historical source snapshot does not include the 2018/2020 updates needed for later training folds. The script parses the entire archive, including other-office 2018 outcomes, before filtering; it uses no 2018 Senate outcomes in the inventory. No fitting, source admission, empirical accuracy finding, or public model change occurs here.
