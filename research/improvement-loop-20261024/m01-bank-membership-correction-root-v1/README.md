They are preserved as issued. **The pinned `compatibility.json` lists the same event-key sets for both arms in all four folds.** H0/F0 counts are 299/299, 329/329, 357/357 and 387/387 for targets 2018, 2020, 2022 and 2024; symmetric differences are all zero. The underlying `verification.json` reported those aggregate counts correctly. `check.py` reproduces the corrected full set comparison and verifies the original metadata digest.

The previous calibration-overlap conclusion is unaffected: all 59, 85, 106 and 106 calibration event keys respectively are in each arm's listed training keys. This is still not a claim that the underlying native likelihood is duplicated or that using a normalized conditional model is valid for the actual joint graph. The F0-only export is not a general per-arm ownership ledger; equality here is an observed property of this pinned metadata, not a rule imposed on future banks. Original bank-file equality and native factor ownership need separate checks.
