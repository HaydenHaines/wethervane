# Economic source intake: root review

October 25, 2026 UTC. This is data preparation for the requested gasoline/inflation research, not an estimated electoral effect or a qualified forecast.

## Inflation

[The CPI intake](economic-vintages-v1/README.md) preserves 15 BLS release PDFs from the Federal Reserve Bank of St. Louis's FRASER archive. Direct BLS downloads returned 403 and remain recorded; the alternative consists of actual archived release copies, not a present-day FRED series or text invented from search snippets. The intake covers every even cycle from 1998 through 2024, plus a deliberately post-cutoff 2014 release. Table 1 supplies 30 headline/core twelve-month NSA rows and 28 selected values at the declared H14 cutoff.

[Independent Luna review](cpi-vintage-review-luna.md) checked all 28 selected values against the source narratives/tables. Root inspected the parser, source/units/time checks and selection logic, verified the 2014 release timing against the BLS archive, and ran the corrected eight-test suite. All eight pass. A source is preserved by hash; the document's dated embargo supports nominal publication timing, without proving that neither archive host ever corrected the file afterward.

Two review fixes are implemented. The staleness limit now rejects releases older than exactly 90 days, including an additional second. Numeric Table 1 cells now parse complete optional revision-marked values: `R2.5` stays 2.5 instead of silently matching a numeric suffix. Tests cover both. The 2016 prescription-drug correction flag is explicitly document-level; it is not evidence that the selected NSA September headline/core observations were revised. Original PDFs and all 28 selected values remain unchanged after these repairs.

The H14 convention here is **23:59:59 UTC on election day minus fourteen calendar days**. This is a declared research convention, not automatic compatibility with the model owner's midnight or exact-time cutoff. The 2004 release arrived on the cutoff date at 12:30 UTC; earlier that day this bounded inventory correctly returns unavailable. In 2014 the September release arrived October 22, after the October 21 H14 cutoff, so August must be selected. [BLS's September 2014 release](https://www.bls.gov/news.release/archives/cpi_10222014.htm) confirms that date. An owner adapter must bind the actual comparison cutoff before these values enter a fitted model.

The four primary replay pairs (headline/core percent changes) are 2018: 2.3/2.2; 2020: 1.4/1.7; 2022: 8.2/6.6; 2024: 2.4/3.3. These national observations supply cycle-level information, not hundreds of independent race observations. Their availability does not admit a complete earlier-election outcome panel or identify a multi-feature economic coefficient.

## Gasoline

[Luna's EIA audit](gasoline-vintage-audit-luna.md) recovered the latest Monday price and its 13-week comparison for each primary H14 cycle from archived Wednesday summaries. Root independently extracted all eight values from the dated national retail table context, checked all ten raw hashes, confirmed each comparison spans 91 days and reproduced the changes. [The check receipt](evidence/gasoline-source-replay-root-v1.json) records that scope and the one Windows-1252 HTML decode fallback.

The Wednesday reports are **after** the Tuesday cutoff. EIA's historical Monday release schedule supports an inference that those values were already published, but does not prove the exact Monday posting or absence of an intervening revision. Each pair therefore has `strict_asof_qualified: false` and `historical_schedule_proxy: true`. The correction from an initially stronger availability claim is retained. EIA changed its usual publication schedule in April 2025; [the official notice](https://www.eia.gov/petroleum/gasdiesel/notice.php?fs=e&s=cl) prevents projecting today's Tuesday schedule back onto the earlier cycles.

A [separate TWIP panel](gasoline-twip-cutoff-v1/README.md) now uses the latest archived report dated before each H14 cutoff, retaining both issue and observation dates. It covers all twelve even cycles from 2002–2024. Its four A/B current/91-day-lag prices are 2018: $2.879/$2.865; 2020: $2.167/$2.195; 2022: $3.871/$4.490; 2024: $3.171/$3.496 per gallon. These older observations are a different source/horizon arm and must not be relabeled as the latest GDFU price or silently substituted into the proxy panel. The May 2018 gasoline sampling break remains explicit.

[Independent review](gasoline-twip-review-luna.md) caught a manually copied 2004 heating-oil value (189.9 cents) in the review evidence. The actual gasoline cell and prose say 199.3 cents; the repaired intake has a regression checking both columns. Its October 2004 source header mistakenly says 2003. Admission uses a narrow exception bound to the exact source/index bytes, source URL, header literal, observation date and calendar corroboration; it never silently changes arbitrary source years. The raw contradiction stays visible. The July value is 191.7 cents, exactly 91 days earlier; the derived log change is 0.038879577167. [A second independent delta review](gas2004-review-luna.md) verified the repair, and root ran all five tests successfully.

Reports lack exact posting timestamps. A conservative end-of-following-UTC-day availability bound precedes each declared cutoff; neither this bound nor the explicit 2004 exception authenticates original posting logs or rules out later archive revisions. Both original-posting authentication flags remain false. This is stronger nominal pre-cutoff source evidence than the later-report schedule proxy, not qualification of a full strict historical forecast.
