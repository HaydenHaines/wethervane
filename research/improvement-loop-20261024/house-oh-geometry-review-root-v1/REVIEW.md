# Independent Ohio geometry arithmetic review

The saved descriptive comparison's exact bytes and all nine declared source pins matched before and after review. I independently recalculated 30 pairwise comparisons across 15 Ohio district labels using `(A − B) + (B − A)` for symmetric difference and `area(A) + area(B) − area(A ∩ B)` for union, in EPSG:5070. Compared with the saved results, the maximum absolute discrepancy was approximately 2.5e-12 square kilometers and 5.0e-16 in the union fraction. The owner's two validation tests passed. Re-running the owner's own `run()` separately also reproduced all 30 values. These checks used the same GeoPandas/Shapely environment as the owner, not an independent geometry engine.

The [Ohio Secretary of State's district maps page](https://www.ohiosos.gov/elections/district-maps) states that the congressional plan adopted in October 2025 is used beginning with the 2026 election cycle. Direct access to the linked statutory shapefile ZIP returned HTTP 403 in this environment; the captured state-hosted GIS layer has not thereby been proven byte-identical to that package. The independent arithmetic check uses the owner's captured layer, Census ZIP, and simplified display geometry, all as pinned in the result.

The measurements are area differences, not estimates of voters affected, legal map correctness, whole-block assignments, or precinct presidential vote allocation. The state capture postdates the forecast cutoff, and prior identical bytes are not established. The state and Census layers may share upstream sources. This review does not admit any map, resolve causes of differences, validate the full House release, or authorize a website change.

Run `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B reproduce.py` in this directory with the House benchmark GeoPandas environment. The script verifies all saved input hashes and emits aggregate numerical differences only. No owner file or model job was modified.
