Historical Senate poll intake — October 20, 2026

The [single-source development panel](derived/historical_poll_panel.csv) contains 1,837 polls from four admitted cycles. It is usable for retrospective aggregate polling-error development and rolling-cycle comparisons with an explicit field-date availability approximation. It does not qualify a strict historical real-time forecast. No fitting, tuning or scoring was performed here.

[Outcomes](derived/outcomes_allowed_cycles_SEPARATE.csv), [fundamentals features](derived/race_inputs_allowed_cycles.csv), and the [full allowed-cycle roster](derived/race_roster_allowed_cycles.csv) are separate exports. They retain every eligible race, including unpolled races. Features provide strictly earlier presidential two-party shares, source candidate identity and incumbency; they are the existing limited aggregate baseline inputs, not newly authenticated historical fundamentals posterior draws. Their metadata were extracted from later corrected archives, so their pre-election availability is not independently established. The existing roster's conservative scope excludes specials, simultaneous special states, GA/LA systems, applicable RCV and non-D/R contests. It is an existing comparator scope, not a nationwide all-candidate Senate panel.

The byte-authenticated author source is [Tierney–Volfovsky's replication repository](https://github.com/g-tierney/polling_errors_replication/tree/4aba5bc539dde8157bb2eeae9f3330a01439c19d), commit `4aba5bc539dde8157bb2eeae9f3330a01439c19d` dated March 8, 2023. Its `data/polls_cnn_dataset.csv` contains Senate cycles 1992–2020. Only 2012/2016/2018/2020 polls enter this export; author outcome columns are excluded at poll ingestion. The preserved UTF-8 file exactly matches Git blob `2b397788b99435522a7f051a4040bcd913c693f6` and SHA-256 `61e1141f5ed84cfbbec487115742f59c6e20ebd04ba99a0a32f08d8fa2b20322`. Its original pollster releases and the transformation generating its D/R values remain unverified.

The normalized first candidate is the Democratic candidate. `first_candidate_conditional_share` and `dem_share` equal `source_democratic_value / (source_democratic_value + source_republican_value)`, on a fraction scale. This explicitly conditions on the D/R pair; other/undecided/refused categories are not identified by this source. Share error in percentage points is `100 * (q - q_outcome)`. Conditional D-minus-R margin is `2*q - 1`, so its percentage-point error is twice share error. Logit values are dimensionless; `days_to_election` is calendar days measured from the corrected election date. The author's preparation script additionally uses `days_to_election / 30`; that quantity is thirty-day periods, not days or exact calendar months.

Two consequential source defects are retained explicitly:

- All 2,016 allowed-cycle raw author rows have D+R equal to `numberOfRespondents`. Those D/R values are therefore consistent with derived two-party totals, not released percentages. Integer formatting does not prove raw independent respondent counts. The export preserves the values, `reported_n`, and an unknown-original-sample basis. `effective_n` and sampling `variance` stay missing. Copying the author's percent-based `N*(D+R)/100` preprocessing would produce `N*N/100` for these rows and is not an admitted sampling-size calculation.
- Every 2016 source row records election date `2016-11-03`; the admitted roster records `2016-11-08`. Only that exact known discrepancy is corrected. `source_election_date` and `election_date_correction` preserve the original and reason. Field dates are unchanged. Consequently the observed 2016 series ends nine days before the actual election, and 14 rows are now 101–105 days before it. They remain visible; any 100-day inclusion rule belongs to the frozen experiment.

The author file has no candidate names/IDs, original publication timestamps, verified historical revision ledger, field starts, source URLs, sample IDs, respondent universe or mode in these cycles. The candidate join is therefore a unique eligible state/cycle D/R roster mapping, not an exact author-name verification. All rows carry that distinction. Election date must match the roster after the one documented correction. Of 2,016 raw allowed-cycle rows, 179 lie outside the existing eligible roster; none are selected using observed poll shares or election errors. There are no exact duplicate retained author rows or conflicting same-pollster/race/end-date groups in this subset. Repeated samples, overlapping panels and cross-state releases remain unknown; row IDs do not establish sample independence. Potential overlap groups retain source, cycle and pollster.

`available_date` in this panel is a **field-end proxy only**. `publication_date` is missing and `publication_date_verified`, `historical_version_verified`, and `strict_asof_qualified` are false throughout. An experiment must say that it assumes field-end availability and assess sensitivity to a release lag; it cannot call this verified public information at each cutoff. The [538 alternative](derived/cached_538_poll_catalog.csv) supplies 445 observations / 26 races in 2018 and 435 / 25 in 2020 using the existing exact publisher race/candidate-ID gate and question normalization. Its [cutoff-specific table](derived/cached_538_cutoff_specific_catalog.csv) includes 90/30/14/7/1-day cutoffs; availability is applied **before** choosing alternative questions from one sample. It preserves weighted reported D/R percentages, nominal question N, universe, mode, publisher URL, sample/question IDs, and ingestion timestamps where present. Its availability is `created_at + one day`, conservatively also requiring the field end before cutoff, still a proxy rather than verified publication. The input is the pinned March 5, 2025 Internet Archive snapshot acquired October 7, 2026: `.redesign-runtime/forecast-20261007/polls/senate_polls_historical.csv`, SHA-256 `09ae303a94f76dd761532fce7a356fe3b5beb1e24d4e5ba343c424c372fdfabf`. Actual cycle metadata are 2018/2020/2022/2024; this archive supplies no 2012 or 2016 Senate polls. Retrospective quality ratings were excluded at ingestion. There are zero known shared sample IDs across retained eligible races in these exports; hidden shared panels remain possible.

The [Stanford auxiliary alternative](derived/stanford_poll_catalog.csv) adds 783 2012 polls / 23 eligible races with percentages, population and mode, but no field starts, publication dates or underlying sample IDs. It comes from [the author's pinned repository](https://github.com/stanford-policylab/polling-errors/tree/02475af7ebe7951c2b94fd0714cf4e2cc15893b1), commit `02475af7ebe7951c2b94fd0714cf4e2cc15893b1`, dated February 7, 2018. Its source blob `8b30dc7ec6ce3291157fa84f625e52c32980049b` exactly matches the auxiliary TSV also distributed in the Tierney repository: those two copies are the same evidence. The alternative contains two same-pollster/race/end-date groups with differing source values; both remain marked with unknown sample identity. Source README attributes the auxiliary data to Pollster.com and RealClearPolitics. No repository LICENSE was present in the inspected trees; local intake does not establish redistribution permission.

These sources should be compared as alternatives. They must not be concatenated as independent polling evidence: author rows may reproduce the same original releases as 538 and Stanford, and exact cross-source sample linkage is not available. Use the 1,837-row author panel for consistent-source rolling development; treat the richer 538 panel as a separately labeled source/coverage sensitivity analysis.

With the current data, one can freeze a conventional aggregate normal/logit working-error model using 2012/2016, predict 2018, then allow 2018 into training before predicting 2020. One can estimate cycle/race/pollster error and horizon dependence under stated identifying assumptions, compare transparent P/FP-static/dynamic algorithms on identical poll inputs, score polled and unpolled roster races, and quantify sampling uncertainty by cycle. Two scored cycles are only two national tests. The current file does not supply a direct sampling/design covariance, original publication-safe history, verified same-sample overlap, a complete all-candidate likelihood, respondent community bridge, or enough evidence for causal community explanations. Historical fundamentals distributions still need to be regenerated within earlier-cycle folds; this intake supplies inputs, not fitted draws.
