## Immutable export and provenance

Full `export()` returns immutable copied `arrays` and `metadata`. Numeric arrays have forecast chain/draw axes; metadata binds race identities, source pins, phase contract and authentic final per-chain RNG states. `save_trace(export,path)` writes exclusively to a new directory: numeric-only `trace.npz`, `provenance.json` and `receipt.json`. It returns the receipt and its external SHA. `load_trace` requires both expected source pins **and an externally bound expected receipt SHA**, checks file bytes and exact array/dtype/shape/phase schema with `allow_pickle=False`, and returns immutable copies. A colocated receipt alone is not an independent immutable binding; the caller must bind the returned receipt SHA in its job/forecast manifest.

Partial `export_partial()` is a **completed-observer-phase prefix only**, never restartable state or a claim about complete raw predictions. At `completed_sweep`, the original sampler has not yet made retained missing-race RNG calls or assigned raw predictive output. A callback may raise after the observer record while that original predictive draw is absent. Metadata explicitly includes `observer_phase_prefix_only:true`, `raw_predictive_draw_completeness_claimed:false`, `restartable:false` and this count-semantics caveat. Missing final RNG states stay missing; only actual `chain_final_rng` events appear.

Partial arrays use `chain{c}__<name>` with an explicit one-chain leading axis and only initialized observed-sweep prefixes. `forecast_chain_index` and `retained_draw_index` preserve coordinates. Each chain has its own bank-batch sums/counts/occupancy over completed observer records; current pending row-weight mass is excluded, both within a batch and at its boundary. Common observed/missing and source axes remain separate. Full save/load intentionally rejects the partial schema; the runner owns exclusive partial-artifact serialization and its external receipts. A partial's `complete` flag means all requested observer records/final RNG events were received, not that this separate observer artifact contains raw predictions.

## Numerical measurements and gates

- `function_diagnostics`: existing `correlated_mcse` at batch lengths50 and100, maximum MCSE and rank/folded split-Rhat, variance/MCSE² named **mean-ESS estimate**, never bulk/tail ESS. Unexpected constants and numerically unrepresentable mean-ESS remain unresolved; only explicitly declared actual structural constants are exempt. Nonfinite Rhat is an explicit failure with a JSON-safe missing numeric value, not a pass.
- `core_state_diagnostics`: selected observed logits/shares, all six F0 coefficients, tau scales, cycle/cycle_z and **log post-Gamma lambda**. It checks trace/original race, row, cycle and observed-theta identity before assembling coordinates.
- `mean_share_diagnostics`: supplied conditional expected shares, max MCSE.001. It does not substitute logistic(logit-mean) for expected share or compute integrals.
- `log_tail_diagnostics`: independently supplied side-specific log conditional probabilities, logsumexp and shared scaling before MCSE. It retains log probability, log absolute MCSE, relative MCSE and centered per-chain log differences without subtracting from1 or inserting floors. Absolute probability precision(.0025), relative precision(.05) and chain log agreement(.15) are separate gates. Thus a tiny tail may fail relative precision while its absolute probability gate passes; no global veto is implemented. Underflowed absolute-MCSE display is flagged and left missing while its stable log value is retained. All-minus-infinity sides, chain sides without support and constant raw winner indicators remain explicitly unresolved/failing as appropriate, never zero-error certificates.
- `interval_display_diagnostics`: supplied CDF trace MCSE and supplied share-bracket width gates, explicitly display-only. It neither builds quantile brackets nor certifies score precision or requests more sampling.
- `bank_diagnostics`: all-row average mass; max/top10/top100 mass; entropy;1/sum(weight²);99%-mass row support; original-source-chain masses; forecast-chain total variation and source-mass differences. Counts weight pooled averages correctly. Row relabeling leaves substantive measurements invariant. Concentration flags are **inherited-bank approximation warnings**, separate from forecast-chain integration consistency gates; source mass need not be uniform. No numeric row-ID Rhat is used.

BFMI, divergences and tree depth have no role in this Gibbs diagnostic packet. Finite-batch diagnostics do not prove convergence or exclude missed modes. Historical bank error and fixed calibrated-scale uncertainty remain separate from new conditional Gibbs integration error. No scalar overall pass, global retry, selected attempt, label access, score qualification or model win is inferred here.
