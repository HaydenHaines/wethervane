# Independent review: 2018 Delaware EAVS F1a acquisition

**Decision: ACCEPT the bounded source evidence.** The official EAC 2018 public-release Version 1.0 CSV currently hosted at the [EAC archive](https://www.eac.gov/research-and-data/studies-and-reports) contains three Delaware F1a county literals: Kent 60,230; New Castle 212,978; Sussex 93,342. Their sum is **366,550**. The Version 1.3 CSV contains the same Delaware F1a rows. This supports an official 2018 EAVS **reported F1a participation** value for Delaware. It does not turn the absent Delaware state brief into a retrieved brief or authorize a change to the sealed owner panel.

## Independent checks

- Independently parsed both raw CSVs with Python's CSV reader; did not call the author's extraction code or use its calculated totals. Recomputed every recorded file/header SHA-256 and byte length against the author's [receipt](../eavs-2018-delaware-acquisition-sol-v1/receipt.json). The receipt itself is pinned in `receipt.json` here. Separate HTTPS GETs streamed directly into SHA-256 produced the same raw hashes for Version 1.0 (`c524c58c…`) and Version 1.3 (`ae2e763c…`). The EAC archive identifies those CSV paths as Version 1.0 (released June 27, 2019) and Version 1.3 (released July 15, 2020). Captured responses were HTTP 200, `text/csv`, and their `Content-Length` equaled file length. A separate HTTPS HEAD request to Version 1.0 returned HTTP 200, 23,398,381 bytes, and `SSL certificate verify ok` for `www.eac.gov` (certificate subject `eac.gov`, Google Trust Services issuer). The archive and codebook are also direct EAC sources. See [calculation.json](calculation.json).
- Both CSVs have 407 named columns, 6,460 data rows, and 54 state/territory abbreviations. Relevant exact headers are `FIPSCode`, `Jurisdiction_Name`, `State_Full`, `State_Abbr`, `F1a`, and `F2`; `F1a` is at zero-based column 289. The EAC [2018 codebook](https://www.eac.gov/sites/default/files/eac_assets/1/6/2018_EAVS_Codebook.xlsx), sheet 1 row 291, labels F1a “Participation: Total.” The [2018 survey instrument](https://www.eac.gov/sites/default/files/eac_assets/1/6/2018_EAC_Election_Administration_and_Voting_Survey_Instrument.pdf) defines F1a as total voters participating in the general election across modes.
- The three Delaware keys are distinct: `1000100000` Kent, `1000300000` New Castle, and `1000500000` Sussex. Their county stems `10001`, `10003`, and `10005` match the [Census Delaware county GEOIDs](https://www.census.gov/programs-surveys/geography/guidance/geo-identifiers.html). There are exactly three `DE` CSV rows, each with a positive numeric F1a literal and no missing or negative F1a. This establishes coverage of Delaware's three counties in the released CSV; it cannot independently certify the correctness of the counties' reported values.
- Joined by unambiguous `State_Abbr` and checked case-folded `State_Full` against the [owner source panel](/home/hayden/projects/wethervane-redesign-20261006/integration/research/senate-stack-integration-20261020/eavs-2018-source-sol-v1/state-f1a-source-rows.json) at pinned SHA-256 `c56e25352fb4807b717afc777ef2286b0779f22770b073f731bfe58c6048608a`. The 50 existing non-null **state/DC** brief totals equal nonnegative F1a CSV sums in both versions; Delaware remains null in that source panel. This validates numeric alignment, not the original brief publication date or local reporting completeness.
- Missing/sentinel F1a literals remain missing. Both CSV versions contain **31** such rows outside Delaware: Arkansas 14, Hawaii 1, and Texas 16. Version 1.0 has 13 Arkansas blanks, one Arkansas `-99`, one Hawaii `-88`, and 16 Texas `-99`; Version 1.3 retains the same counts but labels the `-99` entries “Data not available.” The 50 matching aggregate sums therefore do not establish complete reporting in those states. Version 1.0 also duplicates FIPS `2402900000` between Maryland Kent and Montgomery rows; Version 1.3 does not. This unrelated source-key flaw does not affect the three distinct Delaware keys.

## Quantity and provenance limits

All three Delaware records have `F2=4` in Version 1.0 and `F2=Votes cast` in Version 1.3. The [2018 instrument's F2d definition](https://www.eac.gov/sites/default/files/eac_assets/1/6/2018_EAC_Election_Administration_and_Voting_Survey_Instrument.pdf) says this method bases participation on votes cast for the highest office on the ballot. Thus the EAC-reported F1a field is the exact question acquired, but its Delaware reporting method is a highest-office-vote proxy. Do not label 366,550 an independently counted physical participant total or substitute it for a candidate-vote target. The original 2018 participation definition also differs from later cast-and-counted EAVS definitions, as documented in the owner [source note](/home/hayden/projects/wethervane-redesign-20261006/integration/research/senate-stack-integration-20261020/eavs-2018-source-sol-v1/README.md).

The [2018 EAC archive](https://www.eac.gov/research-and-data/studies-and-reports) displays Delaware as plain text in the state-brief list, without a linked brief; the expected route returned HTTP 404 in the author's preserved response. These are raw hosted dataset bytes acquired in 2026, not original 2019 release bytes. The archive's release labels and current file contents do **not** prove the exact bytes existed at the June 2019 cutoff. HTTP `Last-Modified` headers reflect later hosting and do not establish 2019 publication identity. Equality with 50 currently hosted briefs likewise does not determine those briefs' publication or revision dates. Any owner admission or forecast use must retain those limits and its own provenance decision.

No owner files, model, scorer, fit, or report profile were changed in this review.
