For an explicitly named first candidate A versus second B, share fraction `s = votes_A/(votes_A+votes_B)` transforms to margin in percentage points as `m = 100*(2*s-1)`. Apply that same monotone transformation to the mean and quantiles; label mean and median separately. Reverse orientation requires reversing quantile tails as well as the sign. No values were transformed during this audit. Never subtract marginal full-field candidate quantiles to invent a margin interval, and never imply the pair denominator includes Other votes.

For a frozen cohort with one modal-winner call per race, the model-implied expected number of wrong calls is `sum_r (1 - max_k p[r,k])`. This uses linearity of expectation and needs no independence assumption or joint draws. State the target: Senate calls are conditional principal-pair winners; House calls are winner groups, with named calls only for singleton outcomes. The expected number is not a predictive band for the number of misses. A miss-count distribution, coordinated-miss probability, or mean absolute margin error cannot be recovered from those winner probabilities. Freeze the modal tie rule separately for realized calls; preserve every cohort race and unresolved result in the denominator. No expected-count value was computed in this audit.

## Reusable adapter boundary proposed for implementation

`adapter-contract.json` specifies the proposed normalized blocks and exact input mappings. It is a proposal for a small adapter, not an implemented backend schema or permission to change an owner contract.

1. **Freeze** one immutable record per chamber and selected saved run: artifact/catalog/review/source pins; run/configuration/target/law IDs; issue/cutoff/source dates, strict-as-of flag, election/rule definition, race/cohort IDs, point-rule definition and interval/event definitions. Keep the preferred run first; only exact catalog choices are selectable. Preserve native qualification and limitations.
2. **Separate targets** within each race: named conditional-pair margin; exhaustive modeled winner vector; chamber scenario. Every scalar carries units, denominator, orientation and support. Nullable availability includes an explicit reason. A missing pair never becomes a zero margin; a pooled winner never becomes a person's probability.
3. **Freeze evaluation choices** before results: illustrative-race and competitive-cohort selections with forecast-time reasons; baseline identities; scoring formulas, tie conventions, result-finality rules, metric units/weights and shared-miss diagnostics. These need research and owner review. Do not imply component switches causally attribute a forecast to a mechanism.
4. **Keep results separate and versioned**: result source/pin/URL, retrieval/publication timestamp, contest/round ID, candidate/group mapping, denominator, counted-vote status, call status, certification/finality status and result revision. Called winner and final margin are independent fields. A runoff or RCV final-preference target stays pending until the relevant rule/round is resolved; unsupported source-to-target mapping stays ineligible.
5. **Compute scores only from eligible truth** in a later authorized implementation: signed margin error explicitly `observed minus frozen forecast` in pp; absolute error; proper score for the exact margin/winner/chamber target; interval coverage *and* width; comparable baseline differences and unresolved denominator. The initial record has pending results and no numerical scores. Never replace the frozen forecast with an in-play update.
6. **Expected error and joint behavior are optional reviewed exports**, never fabricated from summary quantiles. Specify the point rule first, e.g. `E[abs(M_draw - frozen_point)]` in pp for a named-pair marginal; an aggregate expected-error distribution must use the same row across the declared race cohort. State this as the model's implied expected error, distinct from historical empirical error. Preserve sample layout/weights and source identity. Shared-error event definitions and tail probabilities need pre-outcome review. Chamber PMFs support their declared univariate seat target, not arbitrary joint margin claims.
7. **Grades remain `not_graded`** until a researched, source-bound rubric is approved. Point, probability/distribution, interval and dependence assessments remain separately available. No user configuration saving is introduced.
