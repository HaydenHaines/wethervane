## Blockers before an actual pilot

It never applies execute() freshness/selected queue/harness pins/protected-root/scratch/RealSensors leaf/resource/owner checks. The mock intercepts the first join write with admission.json absent, preventing all writes/imports. This crosses the intended controller-only worker entry boundary under accidental direct invocation; it is not anti-forgery against arbitrary same-user Python. A complete handmade admission can choose its own source_pins/runtime/source path; no inherited parent capability gates it. Require controller-linked inherited descriptor/parent identity and worker-side pre-mutation envelope validation. No need to claim impossible same-user hostility protection.

2. Lost owned-child handle after Popen (129–133): birth(p.pid) occurs before appending to children. Mock Popen returns an invented process; injected PermissionError from birth leaves children empty despite Popen success. A real child still in Python bootstrap may be outside the leaf; group cleanup cannot cover it. Retain Popen immediately, then attach identity/handshake under a try/finally with explicit unknown-identity owned-handle teardown/reap semantics. Do not signal a guessed PID. This is an exception-boundary flaw independent of hostile code. No real leaked process was created here.

3. Newly added descendant-group cleanup ambiguity (160–167): startup validate_leaf rejects child groups, but cleanup does not repeat that check. In an ordinary temporary fake group with populated1, empty direct cgroup.procs and unknown-child directory, cleanup writes cgroup.kill despite authenticating no members. Linux group kill covers descendants. The fake test writes only a temporary regular file; no signal occurs. Refuse kill on unexpected descendants or authenticate an explicitly owned recursive tree with retained ownership. A trusted exclusive-leaf assumption reduces likelihood but must not be silently extended to newly observed descendants. Current code has no lease preventing a cooperating external cgroup writer from adding a subgroup. Even recursive enumeration cannot prove safety against arbitrary hostile between-check migration; document residual trust/race explicitly.
