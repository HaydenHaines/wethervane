# Historical poll source crosswalk review (Luna v4)

## Result

No complete, authenticated pre-2018-10-23 Senate poll/question/sample crosswalk was found. The best next route is a *manually source-linked subset*: start with the pinned May 2018 FiveThirtyEight pollster-ratings archive, and resolve candidate rows against dated original pollster releases. I verified one 2016 Missouri Emerson event this way. This demonstrates a workable source-to-538 event bridge for a row; it does not validate all candidate rows, supply stable respondent/sample IDs, or reconstruct exact questionnaire text.

For `2016_Sen-G_MO`, FiveThirtyEight archive row `pollno=76050` records Emerson College, date 11/5/16, N=750, Democrat 45.5%, Republican 44.8%. Emerson's original release is dated November 7, 2016. It says its Missouri survey was conducted Nov. 4–5, all samples were likely general-election voters, Missouri N=750, and reports Kander 46% to Blunt 45% in the narrative. Its detailed frequency table gives Kander 341/750=45.5%, Blunt 336/750=44.8%, someone else 40/750=5.3%, undecided 33/750=4.4%. The field-date midpoint is Nov. 5, so the 538 `polldate` has the expected median-date interpretation. The release's date, state, pollster, population, N and exact topline are jointly strong evidence that this is the same poll event represented by 538 row 76050. The contemporary pollster release is the authoritative evidence; the current RCP historical table independently displays Nov. 4–5, Kander 46, Blunt 45 and links the release, but its current page does not prove its page contents or data lineage as of the 2018 cutoff.

The Emerson release's accessible material does not provide a stable sample ID, a question ID, respondent microdata, or exact Senate ballot question wording. Its frequencies identify the survey event and reported tabulation, but cannot prove the exact instrument wording or respondent/sample bytes. This is therefore a verified **poll-event** crosswalk, not a question/sample-ID crosswalk.

## Challenge to the May 2018 538 archive assessment

- The source file and commit are genuinely useful: the pinned 2018-05-30 CSV includes 2012/2016 Senate general rows, has a 538 `pollno`, a field-date median, a sample-size field and candidate shares/outcomes. The local captured CSV hash is SHA-256 `79489a9d7f796d8f50841e91d8dcb858679ada75690812d4757f095a107efb91` (Git blob SHA-1 `39675528c20d57e88fbb1147ee10f6295f7061da`). Its source commit is `142cad5610ed6b3468e730199034b280b9e805d5`, shown with a 2018-05-30 timestamp in GitHub's primary commit page.
- The 538 row does not record the population; only the original Emerson release supplies the likely-voter definition. The source documentation/article describes a late-cycle dataset: polls in the final 21 days. The local archive audit sees 465 2012/2016 Senate general rows with poll dates 2–21 days before the associated election. This is not a cycle-complete polling panel and does not support an unbiased all-cycle time-series without a separately justified scope.
- The Emerson record shows at least some 538 rows can be manually confirmed to original releases with exact N and exact unrounded-to-integer reported toplines. It is a positive validation example, not a basis for treating the other automated name/date/share candidates as verified.
- A FiveThirtyEight 2024 “State of the Polls” dataset is a later, useful forensic index. Its README describes 2012/2016/2020/2024 files containing polls ending 180–15 days before each election and columns for start/end dates and whether a Senate question exists. It is post-target, has no question text, sample size, poll-level source link or respondent/sample ID in the documented schema, and is not evidence of a 2018-as-of source vintage. It cannot repair the 2018 archive's missing source lineage.
- Current RCP pages expose old poll listings and several direct source links, but are mutable contemporary pages. I could not retrieve an Internet Archive CDX response or establish a pre-cutoff RCP page snapshot in this pass. Do not treat current page values as contemporaneous snapshot bytes.

## Strongest next obtainable route

Use the pinned 2018 538 file as a *screening frame*, not a complete poll archive. For every admitted candidate row, manually require an original pollster or sponsoring publisher release that supplies state/race, survey field dates, population, sample size, and topline; save the release's publication date separately from the field interval. Preserve the 538 ID only as an archive ID. Keep a categorical confidence level: source-release-to-538 poll-event match may be verified, while exact item wording and sample/respondent identity remain unavailable unless the pollster provides the instrument or microdata.

The University of Texas/Texas Politics Project archive is a promising primary-source partial bridge for Texas-only polling: its archive pairs named poll waves with poll summaries, crosstabs, codebooks, data files and methodology statements, and describes matched-down sample sizes and field periods. It is a pollster's own survey archive, not a cross-pollster Senate archive; it covers Texas registered-voter surveys only, not all states, and the current archive page is not proof of the date when all legacy files first became public. It can support a prospective, source-specific Texas study only after verifying each release/file's original dated availability and outcome timing. It does not make a national 2018 Senate replay.

## Reproducibility and capture limits

No new source data or PDF was copied. Emerson's PDF may be subject to publisher copyright, and shell retrieval was unavailable in this environment; the primary URL and observed fields are recorded in `evidence.json`, with no fabricated local byte hash. The 538 source file is reused from its existing CC-BY capture; no original source packet was modified. The Wayback/CDX endpoint was not accessible through the web retrieval tool, so RCP snapshot availability remains unresolved rather than disproven. No source rows were admitted and no model was fit.
